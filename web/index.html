🔒 أوامر قفل وفتح الإنترنت لجهاز (قفل / فتح اسم_الجهاز)
التحكم السريع في حجب أو فتح الإنترنت لأي جهاز برسالة واتساب.
🔌 أوامر قفل وفتح منافذ الفلاشات USB (قفل usb / فتح usb اسم_الجهاز)
قفل أو فتح الفلاشات لجهاز معين أو لمجموعة كاملة عبر واتساب.
🏢 أوامر قفل وفتح مجموعة كاملة (قفل مجموعة الاسم)
قفل أو فتح الإنترنت لفرع أو قسم كامل برسالة واحدة.
🌐 أوامر سماح وحجب المواقع (سماح / حجب موقع.com)
إضافة موقع للمسموح أو المحظور ومزامنته مع كل الفروع فوراً.
📂 أمر استعراض وسحب ملفات الأرشيف (ملفات + هات 1)
يعرض آخر الملفات المسحوبة ويرسل لك أي ملف منها في المحادثة.
🖥️ أمر استعلام كود وباسورد RustDesk (راست اسم_الجهاز)
يرسل لك الكود وكلمة المرور الدائمة جاهزة للنسخ لفتح الجهاز من هاتفك.
⬆️ أمر تحديث نسخة العميل عن بُعد (تحديث اسم_الجهاز / الكل)
دفع التحديث الجديد للبرنامج لجهاز محدد أو لجميع الأجهزة.
⚡ أوامر إعادة التشغيل والإيقاف (ريستارت / ايقاف اسم_الجهاز)
إعادة تشغيل أو إيقاف تشغيل جهاز فرع عن بُعد (أو الغاء ايقاف).
💾 أمر سحب نسخة احتياطية فورية (نسخة / باكاب)
يأمر السيرفر ببدء سحب وفحص نسخة جديدة من موقع الشركة فوراً.
🎥 أوامر وجولات كاميرات Dahua (داهوا / جولة / هاردات)
يسحب لقطة HD لأي فرع، أو جولة مصوّرة لكل الفروع، أو هاردات لفحص سلامة التسجيل.
👆 أوامر البصمات وحضور الموظفين (بصمات / سحب البصمات / حضور الاسم)
يفحص حالة ماكينات البصمة أو يسحب الحركات أو يعرض مواعيد حضور وانصراف أي موظف بالاسم خلال الأسبوع (مثال: حضور كرم أو حضور ميلاد).
✨ اختصارات وأوامر مخصّصة من اختيارك (اختياري)
اكتب أي كلمة مختصرة تحبها متبوعة بعلامة = والأمر الذي تنفذه (كل اختصار في سطر مستقل). مثال: 1 = حالة أو كام اكتوبر = كاميرا October Sales-1
