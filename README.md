# نظام قفل الإنترنت للموظفين 💻🔒

نظام متكامل لقفل الإنترنت والسماح بمواقع محددة فقط، مع حماية بكلمة سر وسجل للمحاولات.

---

## الملفات الرئيسية

| الملف | الوظيفة |
|-------|---------|
| **قفل-الانترنت.bat** | يقفل الإنترنت ويفتح المواقع المسموحة فقط |
| **فتح-الانترنت.bat** | يفتح الإنترنت مرة أخرى |
| **تعيين-كلمة-السر.bat** | يضع كلمة سر لحماية السكربت |
| **تفعيل-التشغيل-التلقائي.bat** | يجعل السكربت يشتغل مع Windows |
| **ايقاف-التشغيل-التلقائي.bat** | يوقف التشغيل التلقائي |
| **allowed-sites.txt** | قائمة المواقع المسموحة (عدّلها حسب احتياجك) |
| **blocked-sites.txt** | قائمة المواقع المقفولة (للوضع blacklist) |

---

## طريقة الاستخدام السريع

### 1. قفل الإنترنت
```
double-click على: قفل-الانترنت.bat
```

### 2. فتح الإنترنت
```
double-click على: فتح-الانترنت.bat
```

### 3. إضافة مواقع جديدة
1. افتح `allowed-sites.txt` بـ Notepad
2. أضف الموقع في سطر جديد
3. احفظ الملف
4. شغّل `قفل-الانترنت.bat` تاني

---

## الميزات المتقدمة

### 🔐 حماية بكلمة سر
يمنع الموظف من إيقاف السكربت أو فتح الإنترنت.

```
1. شغّل: تعيين-كلمة-السر.bat
2. أدخل كلمة السر مرتين
3. من الآن، لن يقدر الموظف يفتح الإنترنت بدون كلمة السر
```

### 🚀 تشغيل تلقائي مع Windows
السكربت يشتغل تلقائياً عند تشغيل الجهاز.

```
تفعيل: تفعيل-التشغيل-التلقائي.bat
إيقاف: ايقاف-التشغيل-التلقائي.bat
```

### 📋 سجل المحاولات
كل محاولة للدخول لموقع مقفول تُسجل في:
```
blocked-attempts.log
```

### 🎯 وضعان للعمل

**وضع Whitelist (افتراضي):**
- يقفل كل الإنترنت
- يفتح المواقع في `allowed-sites.txt` فقط

**وضع Blacklist:**
- يفتح كل الإنترنت
- يقفل المواقع في `blocked-sites.txt` فقط

للتبديل، عدّل `config.json`:
```json
{
  "mode": "whitelist"  // أو "blacklist"
}
```

## نصائح للمدير

1. **ثبّت كلمة السر أول شيء** قبل ترك الجهاز للموظف
2. **فعّل التشغيل التلقائي** عشان السكربت يشتغل مع كل تشغيل
3. **راجع سجل المحاولات** من فترة لأخرى لمعرفة إن كان الموظف حاول يدخل مواقع مقفولة
4. **اختبر السكربت** على جهازك الأول قبل تركيبها على أجهزة الموظفين

---

## استكشاف الأخطاء

### السكربت لا يعمل
- تأكد من تشغيله كـ Administrator (يحدث تلقائياً من .bat)
- تأكد من عدم وجود antivirus يمنع التعديل على Firewall

### المواقع لا تفتح
- تأكد من إضافة الموقع في `allowed-sites.txt`
- بعض المواقع تستخدم عدة domains (مثل discord.com و discordapp.com)

### نسيت كلمة السر
- احذف ملف `config.json`
- شغّل `تعيين-كلمة-السر.bat` مرة أخرى
